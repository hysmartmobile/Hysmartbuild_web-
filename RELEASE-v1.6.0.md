# HySmart Build Web V1.6.0

The Web PWA is aligned with the V1.6 backend contract and adds:

- Procurement workspace
- Requisitions
- Quotations
- Purchase orders
- Goods received
- Supplier invoices
- Supplier payments
- Accounting workspace
- Financial statements
- Chart of accounts
- Accounts receivable
- Payroll
- Banking and reconciliation
- Tax/VAT
- Journals

The package contains `.env.example` only. Configure production environment variables before deployment.
