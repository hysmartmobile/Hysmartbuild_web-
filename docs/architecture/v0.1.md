# V0.1 Architecture

## Request flow

Web / Mobile
  -> Express API
  -> Route
  -> Service
  -> Supabase

The browser and mobile application never receive the Supabase service-role key.

## Service layer

`server/src/service.js` is the application service boundary. Feature-specific services can be added without coupling business logic to Express route handlers.

## Supabase

Supabase provides PostgreSQL and the Supabase platform APIs. V0.1 verifies the database connection through a small infrastructure health table.

## Security boundary

V0.1 establishes the server boundary and environment-secret handling.

V0.2 adds:
- authentication
- user identity
- company membership
- RBAC
- tenant isolation
- RLS
