# V0.6 Architecture — Daily Site Reports, Photos & Progress

Daily reports are tenant-bound to both company and project. The server verifies the project belongs to the authenticated company before reading or mutating reports.

Photos use Supabase Storage (`site-report-photos`) for binary files. PostgreSQL stores only immutable metadata and the storage path; files are not stored as database blobs.

Progress is recorded as an explicit 0–100 value on each daily report, allowing a historical progress trail without overwriting previous field observations.

Project activity remains append-only and records report creation/update/deletion events. The V0.6 migration extends the activity entity type to `SITE_REPORT`.

Authorization continues to use centralized RBAC plus Supabase RLS.
