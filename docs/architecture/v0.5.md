# V0.5 Architecture — Work Management

V0.5 adds project-scoped tasks, issues and an immutable activity feed.

Security remains layered: Express authentication + centralized RBAC + company/project scoping in services + Supabase RLS. `companyId` and `projectId` are never treated as proof of access; the server verifies the project belongs to the authenticated tenant.

Activity is append-only. Database update/delete privileges are revoked for authenticated users so the feed cannot be rewritten through normal client access.
