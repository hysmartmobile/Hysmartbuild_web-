# V0.4 Architecture — Construction Core

V0.4 adds the first construction-domain entities: projects, sites, project team memberships and milestones.

## Tenant boundary
Every V0.4 table carries `company_id`. Express authorization first resolves the authenticated user's active membership for the requested company, then checks the required permission. Supabase RLS provides a second database boundary for direct authenticated access.

## Data relationships
- Company → Projects (one-to-many)
- Project → Sites (one-to-many)
- Project → Project Members (many-to-many users)
- Project → Milestones (one-to-many)

Projects are not deleted in the browser without the `project:delete` permission. Deleting a project cascades to its sites, team memberships and milestones at the database level.

## UI
The 2026 HySmart Build design system is retained: modern typography, generous spacing, compact information density, responsive navigation, clear status chips, accessible forms and role-aware actions.
