# HySmart Build Web V3.6.0

Adds the Production Control experience at `/production`.

Includes:
- Workfront creation and schedule activity linking.
- Readiness checklist management.
- Production capture.
- Productivity and blocker visibility.
- Management focus recommendations.
- Permission-aware navigation under `production:read`.

Web build was not verified in the offline packaging environment because dependencies were not installed. Run `npm ci && npm run build` in CI.
