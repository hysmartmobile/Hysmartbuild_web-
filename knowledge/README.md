# HySmart Build Web PWA v1.7.0

Complete React + Vite frontend for HySmart Build. This release is based on the verified V1.6.2 production Web PWA source and upgrades project operations to match the V1.7 backend APIs.

## Requirements
- Node.js 20+
- npm 10+
- Supabase project
- HySmart Build Node backend running on port 3001 by default

## Setup
1. Copy `.env.example` to `.env`.
2. Set Supabase credentials and `VITE_API_URL` as required.
3. Run `npm install`.
4. Run `npm run dev`.
