# HySmart Build Web PWA V1.8.0 — Integrated Construction ERP

Workflow:
Estimate / BOQ → Budget Baseline → Procurement Commitments → Site Progress → Variations → IPC / Client Valuation → Client Invoice → Retention → Accounting → Profitability → Closeout / DLP.

Includes Executive Command Center, commercial controls, subcontractors, quality, safety, equipment, document control, RFIs, closeout/DLP and the existing HySmart Build modules.

Build note: a fresh Vite build was not claimed because npm registry dependency installation was unavailable in the build environment. Run `npm install` then `npm run build` locally.
